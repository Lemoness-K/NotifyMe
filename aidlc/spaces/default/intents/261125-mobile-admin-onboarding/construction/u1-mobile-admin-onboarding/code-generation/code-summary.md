# 모바일 최초 관리자 등록 구현 결과

## 구현

- 모바일 브라우저에서 기존 Google/Firebase 인증을 거쳐 후보 계정을 표시한다. 설정 시작과 취소를 제공한다. 성공하면 새 로그인 없이 첫 리마인더를 저장할 수 있다.
- `src/server/auth.ts`, `src/server/admin-onboarding.ts`, `src/server/http.ts`에서 후보 전용 권한과 본인 확인, 10분 만료, 중복 요청과 응답 유실 처리를 구현했다. 가구, 최초 ADMIN과 완료 기록은 하나의 SQLite 트랜잭션으로 확정한다.
- `src/server/operations/setup-authority.ts`와 U5 관리형 운영은 명시적으로 준비한 활성 DB·세대에서만 허용한다. 기존 설치의 업그레이드는 자동 개방 없이 진행한다. 운영용 기존 토큰 CLI는 비활성화했고 로컬 합성 테스트 모드는 유지한다. 복원은 후보와 설정 허용을 제거한다.
- `src/web/client.ts`, `src/web/App.tsx`, `src/web/messages.ts`와 스타일에서 후보 흐름과 기존 리마인더 진입을 연결한다. 이메일은 검증된 토큰에서 화면으로 전달하며 DB에 후보 이메일을 보존하지 않는다.
- `D-074` CLI 이력과 후속 `D-099` 모바일 최초 관리자 정책을 연결했다. `Q-048` 최초 등록, `Q-071` Tailscale 범위, `Q-072` 공개 정책, `DS-003` 계정 온보딩, `F-HH-001` 초기 가구 설정 및 `PR-AC-058` 수용 기준의 추적을 갱신했다. 운영 절차는 `docs/u1-local-run.md`와 `deploy/u5/README.md`에 있다.

## 별도 실기기 검증

실제 안드로이드 Chrome, 모바일 데이터와 Tailscale, 비운영 Google/Firebase 로그인은 사용 가능한 물리 기기와 테스트용 설치가 필요하다. 합성 인증 Chromium 결과와 실제 휴대폰의 검증을 구분한다. 이번 단계는 운영 SQLite, 실사용 계정, 서비스 및 Tailscale 공개 설정을 변경하지 않았다.
