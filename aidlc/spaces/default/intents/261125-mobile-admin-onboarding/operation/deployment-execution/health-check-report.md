# 배포 확인과 서비스 상태

[빌드·테스트 결과](../../construction/build-and-test/test-results.md)를 기준으로 Pi의 기존 앱과 별도 테스트 인스턴스를 확인했다.

| 확인 항목 | 결과 |
|---|---|
| 테스트 HTTPS | HTML 200, JavaScript 200 |
| 테스트 로그인 준비 | 클라이언트 설정 200, Google 인증 모드. 같은 출처 요청의 로그인 챌린지 201 |
| 내부 경로 | 테스트 프록시에서 내부 헬스 요청 404 |
| 최초 등록 직후 | 운영자 실기기 검증 및 DB 읽기 전용 대조 통과 |
| 기존 서비스 | 테스트 전·후 시스템 서비스 상태 active, 기존 HTTPS 200 |

기존 운영 DB나 서비스 설정은 수정하지 않았다. 테스트는 Tailscale 내부의 별도 리스너와 임시 권위 볼륨, 전용 SQLite를 사용했다. 공개 노출 정책은 Q-072로 열린 상태다.
