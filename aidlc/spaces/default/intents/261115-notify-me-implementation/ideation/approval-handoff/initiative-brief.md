# Notify Me 착수 브리프

## 목적과 사용자 가치

Notify Me는 가족·동거 가구 구성원이 서로 부탁한 일을 잊지 않고 수행하도록 돕는 공유 리마인더 서비스다. 구성원은 담당자와 시간·장소·반복 조건을 지정하고, 지원되는 Android 기기에서 알림을 받으며, 할 일과 완료 이력을 함께 확인한다. 일반 흐름에서는 담당자가 완료를 표시하면 해당 회차가 완료된다. 완료 검증을 선택한 경우에는 지정 검증자의 판단이 필요하다.

주요 사용자는 가구 구성원이며, 요청 사용자가 제품 범위와 우선순위를 결정한다. 프로젝트 운영자는 저비용의 안정적인 운영과 운영 상태에 대한 가시성을 필요로 한다. 실제 가구 사용자의 별도 사용성 검증은 아직 기록되어 있지 않다.

## 범위와 성공 결과

이번 작업은 기존 설계 문서의 MVP를 상세 설계하고 구현하며, 자동 검증·필요한 Android 확인·Raspberry Pi 배포 준비까지 수행한다. 문서화된 MVP에 더해 다음 두 범위가 이번 작업에 포함된다.

- **Q-063 — Reminder별 선택적 완료 검증:** 담당자가 완료를 제출하면 검증 대기 상태가 되고, 별도 검증자의 승인은 완료로, 거절은 미완료로 처리한다. 권한, 응답 기한, 재알림과 미응답 해소 정책은 열려 있다.
- **Q-064 — 운영자 주간 보고와 즉시 장애 알림:** 운영 보고와 장애 알림을 구현한다. 운영자 자격, 내용, 장애 판정, 전달 채널과 재시도 정책은 열려 있다.

MVP의 기능 기준은 [마스터 설계 §7](../../../../../../../docs/00-master-design.md#7-mvp-제안-범위)와 관련 세부 문서다. 성공은 요구사항과 수용 기준이 설계·코드·검증 결과에 추적되고, 필요한 Android 동작을 확인하며, 배포 준비와 운영 점검 자료가 갖춰졌는지로 판단한다. 운영 계정·실제 개인정보·운영 자격 증명은 자동 검증에 사용하지 않는다.

## 근거, 실현 가능성, 위험

기존 문서는 제품 및 기술의 기준 자료로 계속 사용한다. 현재 설계는 공유 TypeScript UI와 Kotlin Android 어댑터, Raspberry Pi의 SQLite 기반 API, HTTPS 진입 구성을 정의한다. 이 브리프와 이후 산출물은 기존 문서를 대체하거나 deprecate하지 않는다. 기존 결정과의 정합성은 [결정 등록부](../../../../../../../docs/decision-register.md)와 상세 설계를 따른다.

Market Research와 Feasibility 단계는 이번 `classic` 작업 경로에서 실행하지 않았다. 따라서 시장 수요 검증이나 별도 공식 실현 가능성 평가가 완료됐다고 주장하지 않는다. 구현 전 요구사항·설계 단계에서 기존 코드와 문서를 분석해 기술 위험과 미결정을 구체화한다. 별도 마감일·예산·인력 배정은 기록되어 있지 않으며, 현재 자료만으로 다른 가구 구성원의 합의를 가정하지 않는다.

- **R-01 — 검증 대기 항목의 화면 노출:** Rough Mockups 검토에서 minor 위험으로 기록되어 사용자가 수용했다. 검증자의 `할 일`에는 보이고 작업자에게는 별도 탭에서 보여주는 방안은 후보로 남아 있으며 확정하지 않는다.
- **Q-063 — 선택적 완료 검증:** 포함 여부는 현재 작업 범위에 반영했지만 세부 업무 정책은 다음 요구사항 분석에서 결정한다.
- **Q-064 — 운영 보고·장애 알림:** 포함 여부는 현재 작업 범위에 반영했지만 대상·기준·전달 방법은 다음 요구사항 분석과 운영 설계에서 결정한다.

운영 Raspberry Pi에 실제 설치하거나 서비스를 외부 인터넷에 공개하는 작업은 제외한다. 배포 산출물과 사전 점검·복구 절차를 준비한다. 추가 비용이 들거나 별도 외부 계정·서비스를 요구하는 선택은 사전 승인 없이 전제하지 않는다.

## 후속 범위

MVP 이후 기능은 현재 구현에서 제외하고 [우선순위 백로그의 후속 작업](../scope-definition/intent-backlog.md#제외-및-후속-백로그)에 보존한다. 사용자는 이번 확인에서 “ㅇㅇ 지금 당장 그 작업들은 제외되고, 나중의 작업에서 추가하도록 하자”라고 재확인했다. 이후 작업에서 필요한 항목을 골라 새 범위와 우선순위를 정한다. iOS 앱, 추가 인증 제공자, 계정·가구 종료 흐름, 고급 검색·반복, 데이터 내보내기, 유료 기능 및 외부 서비스 연동은 이번 구현에 추가하지 않는다.

## 착수 권고

**진행 권고: Inception으로 진행.** 기존 제품·기술 기준을 보존하고, Q-063·Q-064의 요구사항과 추적 항목을 구체화한 뒤 설계와 구현으로 넘어간다. R-01과 시장·인력·예산 검증의 한계는 열린 상태로 관리한다. 실제 Raspberry Pi 설치와 공개는 이 작업의 완료 조건에 포함하지 않는다.
