# Notify Me 의도서

## 해결할 문제

- Notify Me는 가족·동거인 등 그룹에 속한 구성원의 부탁을 잊지 않고 실행하도록 돕는다. [Q1]
- 일반적인 완료 흐름에서는 담당자가 완료하면 해당 회차를 완료로 처리한다. [Q1]
- 완료 검증은 Reminder별 생성·수정에서 선택적으로 켜고, 담당자와 다른 가구 구성원을 검증자로 지정한다. [Q10] [Q11]
- 완료 검증이 켜진 회차는 담당자가 완료를 표시하면 `검증중` 상태가 되고, 지정 검증자가 확인하면 완료된다. [Q10] [Q11] [Q14]
- 검증자가 거절하면 회차를 미완료로 되돌리고, 응답이 없으면 `검증중` 상태를 유지한다. 필요하면 검증자에게 알림을 보낸다. [Q14]

## 대상 고객

- 첫 사용자는 가족·동거 가구의 구성원이다. [Q2]
- 제품은 구성원 사이의 요청·리마인더, 시간·장소 알림, 완료 이력 공유를 다룬다. [memory:M2]

## 성공 기준

- 문서에 정의된 MVP 수용 기준을 구현하고 자동화 검증과 필요한 Android 확인을 통과한다. [Q3]

## 추진 계기

- 사용자는 기존 설계 문서를 토대로 상세 설계와 구현을 진행해 Notify Me를 완성하고자 한다. [desc]
- 이 요청 외에 별도 일정이나 외부 착수 계기는 없다. [Q4]

## Initial Scope Signal

- Workflow-selected scope: `classic`. [scope]
- 첫 버전은 현재 설계 문서에 정의된 MVP만 포함하고, 후속 기능은 이번 작업에서 제외한다. [Q12]
- 이번 작업에는 코드, 검증, 배포 준비가 포함되지만 실제 Raspberry Pi 설치와 외부 공개는 포함되지 않는다. [Q9]
