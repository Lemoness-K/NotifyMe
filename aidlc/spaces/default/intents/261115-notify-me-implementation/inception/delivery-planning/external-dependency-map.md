# 외부 환경과 검증 의존 관계

## Sources

`requirements.md`, `unit-of-work.md`, `contract-summary.md`, `team-practices.md` 및 프로젝트 운영 설계를 기준으로 했다. Bolt는 독립된 완료 조건으로 진행하는 구현 묶음이다.

| 의존 항목 | 필요 구간 | 책임과 필요한 시점 | 준비되지 않은 경우 |
| --- | --- | --- | --- |
| 비운영 Firebase·Google 프로젝트 및 합성 테스트 계정 | B1 U1, B4 U4 일부 | 환경 소유자 승인 및 AI 개발자 준비. 실제 공급자 검증 시작 전 확보. 리드타임 미확정. | 로컬 공급자 또는 에뮬레이터로 통합 경로를 확인한다. 외부 로그인 결과는 검증 대기로 둔다. |
| 비운영 FCM과 테스트 설치 | B4 U4 | 환경 소유자 승인 및 AI 개발자 준비. 실제 갱신 신호 전달 확인 전 확보. 리드타임 미확정. | 합성 신호와 어댑터로 재시도와 중복 방지를 검증한다. 실제 전달은 검증 대기로 둔다. |
| Android 에뮬레이터와 승인된 실기기 | B4 U4 | AI 개발자가 에뮬레이터를 준비한다. 기기 소유자는 실기기 검증 전에 사용을 승인한다. 리드타임 미확정. | 로컬·에뮬레이터 결과와 미검증 OS 동작을 별도 기록한다. |
| Raspberry Pi ARM64 또는 승인된 검증 환경 | B5 U5 및 Performance Validation | AI 개발자는 대상 환경에서의 검증 계획을 만들고 환경 소유자는 사용을 승인한다. 실제 운영 설치는 이번 범위 밖이다. 리드타임 미확정. | 격리된 개발 환경에서 테스트 데이터로 복구한다. ARM64 호환성과 대상 성능 합격은 검증 대기로 둔다. |
| 실제 프로젝트 검증 명령 및 실행 환경 | B1 U1부터 각 검증 | AI 개발자가 코드·테스트와 함께 준비하고 사용자가 첫 실행 전에 명령을 승인한다. | 현재는 명령을 정하지 않는다. 실제 검증 수준 또는 런타임이 빠질 경우 이유와 남는 검증을 공개한다. |

테스트용 자격 증명과 실제 운영 비밀값은 분리한다. 외부 유료 서비스나 새 사업자 계정이 필요해지면 승인된 범위와 먼저 대조한다.
