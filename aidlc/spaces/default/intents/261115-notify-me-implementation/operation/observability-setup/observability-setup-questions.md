## Consolidated Summary Confirmation

- Raspberry Pi 운영자는 systemd, journald, 로컬 전용 헬스체크와 상태 명령으로 서비스·백업·디스크·RSS를 확인한다. 별도 대시보드와 공개 헬스 경로는 MVP 범위에서 제외한다. D-077과 PR-AC-062를 적용한다.
- 보호 요청 지연과 오류, 프로세스 헬스, 디스크·RSS와 백업 결과를 관측 항목으로 정리한다. 대표 API p95 목표는 500ms다. 측정 구간·부하와 자원 예산은 DS-014에서 확인하며 운영 가용성 수치와 달성 판정은 추후로 남긴다.
- 주간 요약과 장애 기록은 독립적으로 켤 수 있고 기본값은 꺼짐이다. 운영자는 로컬 기록을 확인한다. 외부 전달과 독립 호스트 장애 탐지는 후속 범위다. D-092와 D-098을 적용한다.
- 로그에는 구조화 상태·시각·계수와 허용된 상관 ID를 사용한다. 호스트의 기존 journald 보존 정책을 유지하고, 추가 집계나 분산 추적 서비스는 후속 범위로 남긴다.
- 저장소의 설정·명령과 합성 검증을 기준으로 문서화한다. 실제 Pi에 적용하거나 운영 목표를 측정하는 작업은 별도 검증으로 남긴다.
