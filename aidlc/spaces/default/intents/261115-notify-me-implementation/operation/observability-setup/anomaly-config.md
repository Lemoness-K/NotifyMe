# 이상 징후 확인

정해진 상태 전이와 작업 결과를 중심으로 진단한다. 자동 학습 임계값, 외부 차트와 장기 지표 수집기는 후속 범위다.

| 징후 | 판단 방법 | 확인 위치 |
| --- | --- | --- |
| 헬스 저하와 회복 | 초기 또는 새 `UNAVAILABLE`, 이후 `READY` 전이. `CHECK_FAILED`는 별도 검사 오류 | 관측 유닛과 로컬 상태 |
| 백업 또는 정리 이상 | 실패 코드, 오늘 실행되어야 할 유닛 누락, 최근 백업 상태 | 백업 유닛과 타이머, 보호 상태 |
| 초대 이메일 정리 지연 | U2 설계는 기본 5분 정리와 가장 오래된 만료 데이터의 지연 10분 초과 경고를 요구한다. 운영 로그에 해당 지표가 존재하는지 별도 확인 | U2 모니터링 설계와 실제 앱 로그 |
| 성능·자원 추세 | 같은 DS-014 부하에서 경로별 p95, 피크 RSS, 쓰기량을 비교. 장치나 데이터 조건 변경 시 별도 표기 | 성능 검증 기록 |

실행 내역이 없으면 타이머의 활성 상태, 기능 설정, journal 보존 범위를 먼저 확인한다. 결과 문서에서 기능이 꺼짐, 작업 미실행, 검사 실패를 구분한다. [장애 기록](alarms.md) · [U2 관측 설계](../../construction/u2-household-and-settings/infrastructure-design/monitoring-design.md)
