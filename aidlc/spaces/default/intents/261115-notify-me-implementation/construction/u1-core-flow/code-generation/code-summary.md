# U1 구현 결과

## Summary

최초 가구와 관리자를 설정한 뒤, 공유 웹에서 로그인하고 시간 리마인더를 실제 SQLite에 등록·조회할 수 있다. 서버를 재시작해도 같은 리마인더와 회차가 남는다.

| 영역 | 변경 |
| --- | --- |
| 저장소 | Prisma 스키마·초기 마이그레이션과 가구 범위 조회, 저장 원자성, 중복 요청 처리 |
| 서버 | NestJS 운영자 초기화, 브라우저 인증 요청과 검증된 신원·세션 연결, 가구 인가, 등록·조회, 로컬 헬스, 인증 공급자 검증 기한과 제한된 재시도 |
| 공유 웹 | 로그인·목록·등록, 한국어·영어 리소스, 유동 레이아웃, 세션 만료 처리, 화면 전환 후 미확정 등록 재시도 |
| 실행과 CI | 로컬 실행 안내, 대상 Caddy·systemd 구성 예시, U1 앱 검증 워크플로 |

## Verification

| 검사 | 개발 작업 중 실행 결과 |
| --- | --- |
| 타입 검사 및 빌드 | 통과 |
| Vitest 단위·통합 | 60 / 60 통과 |
| 라인 커버리지 | 82.58% (517 / 626), 목표 80% 충족 |
| Playwright Chromium | 1 / 1 통과. HTTPS 로그인, 잘못된 입력 보존, 화면 너비·키보드·터치, 중복 등록 방지, 서버 재시작 후 실제 SQLite 재조회 |
| CI YAML 및 Caddy 구성 예시 | 로컬 구문 및 네트워크 경계 점검 |

TDD에서 스토리지 3건, 저장소 5건, 업무 규칙 19건, HTTP 5건, 화면 3건, 브라우저 1건의 구현 전 예상 실패를 확인했다. 최종 실행은 현 ARM64 호스트의 로컬 Chromium 및 글꼴 라이브러리 설정을 포함한 `npm run verify:u1`으로 종료 코드 0을 확인했다. 재현 정보는 `docs/u1-local-run.md`에 있다.

수정 전 회귀 테스트에서 공급자 제한과 설정 10건, 웹 세션 종료와 화면 전환 후 등록 재시도 2건이 예상대로 실패했다. 수정 후에는 공급자 기한을 넘은 결과의 폐기, 자격 불일치의 401, 503 이후 화면 유지, 세션 만료의 기존 응답 폐기, 동일 입력 키 재사용과 계정 전환 시 초기화를 확인했다.

## 기존 구현과 문서 변경 이력 재검토

- U1의 [소스 매니페스트](source-manifest.json) 45개 경로는 U1 구현 커밋 `9200199`의 AI-DLC 기록 외 변경 45개와 일치한다. 이후 U2~U5에서 공유 서버·웹·실행 설정을 수정한 이력을 확인했다. U1 매니페스트는 그대로 유지했다.
- [공통 문서 변경 이력](../../code-generation/document-provenance.md)에 기록된 구현 전 문서 5개는 요구사항 분석 승인 커밋 `7022058`과 현재 파일 내용이 일치한다. 각 SHA-256도 Code Generation 시작 시점에 기록된 목록과 일치했다. U3~U5의 구현 중 문서 변경은 `b21d350`, `5bf6785`, `2035730`과 대조했다.
- 최초 구현의 Red/Green 증거는 위 검증 기록에 보존했다. 이번 실행에서는 동일한 구현을 재검증했다.

| 검사 | 현재 체크아웃 결과 |
| --- | --- |
| `npm exec -- vitest run tests/u1/` | 9개 파일, 69개 통과 |
| 승인된 `npm run verify:u1` | ARM64 로컬 환경에서 타입 검사와 빌드 통과. Vitest 32개 파일, 211개 통과. 전체 라인 커버리지 87.26% (2,893 / 3,315) |
| 전체 검증 명령의 Playwright | 4개 통과. U1 시나리오는 로컬 Chromium에서 HTTPS 리마인더를 등록하고 서버 재시작 뒤 같은 SQLite 데이터를 조회했다. U1 시나리오 전체가 11.8초 만에 시간 초과 없이 첫 시도에 통과했다. |

이번 검증은 저장소의 합성 인증과 임시 데이터를 사용했다. 실제 비운영 Firebase·Google 연동, 대상 Raspberry Pi에서의 배포와 성능은 아래 후속 검증에 해당한다.

## Remaining verification

- 실제 비운영 Firebase·Google 계정 연동, 대상 Raspberry Pi 배포 및 성능, 원격 GitHub Actions 실행은 검증하지 않았다. 브라우저 시험은 합성 인증 경계와 실제 앱·데이터베이스를 함께 사용했다.
- 인프라 자동 추적 검사는 상위 산출물의 ID를 인식하지 못해 실패했다. 기존 인프라 연결 12건의 수동 대조를 유지한다. 여기서 코드 추적표는 별도로 확인한다.
- 설치 알림·FCM 및 계정별 표시 설정의 전체 흐름은 해당 후속 단위에 있다. U1의 프로젝트 검증 명령은 별도 확인 뒤 단위 검증에 사용한다.
