# U1 인프라 설계 초안

## Consolidated Summary Confirmation

- **개발과 대상 환경.** U1 통합 흐름은 로컬 웹·API·SQLite와 합성 인증으로 재현한다. 대상 운영 구조는 단일 Raspberry Pi ARM64, Caddy의 HTTPS 진입, systemd가 실행하는 API, 로컬 영속 SQLite다. 앱·DB·관리 경로에는 공개 접근을 허용하지 않는다.
- **운영 경계.** 코드·정적 파일과 영속 데이터, 환경 설정, 비밀값을 분리한다. 요청 ID와 허용된 상태를 로컬 진단에 사용한다. Raspberry Pi의 성능·자원 합격 조건은 승인된 대상 부하에서 평가한다.
- **자동 검증.** 저장소 CI는 합성 데이터로 앱 빌드와 승인된 테스트·커버리지를 검증하도록 설계한다. 비운영 Firebase·Google 연동은 승인받은 별도 환경에서 확인한다. 실제 Pi 설치, 공개 설정과 운영 배포는 이번 작업에 포함하지 않는다.
- **구현 전 연결 확인.** 코드 계획에 로그인 요청과 공급자 응답이 같은 로그인 흐름에 속한다는 검증, 서로 다른 로그인 응답의 거절 검사, 세션·CI·로컬 운영 경로의 세부 요구사항과 검증 위치를 표시한다.
