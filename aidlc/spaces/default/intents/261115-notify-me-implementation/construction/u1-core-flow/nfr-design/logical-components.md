# U1 논리 구성요소와 검증 경계

## Sources

U1의 `functional-spec.md`, `contract-summary.md`, `performance-requirements.md`, `security-requirements.md`, `scalability-requirements.md`, `reliability-requirements.md`, `observability-requirements.md`, `tech-stack-decisions.md`를 기준으로 한다.

| 구성요소 | 책임 | 장애 경계 |
| --- | --- | --- |
| 공유 웹과 HTTPS 진입 | 로그인, 리마인더 등록·조회, 반응형 화면과 번역 오류 | 잘못된 입력을 화면에서 수정할 수 있게 보존한다. 운영 경로는 노출하지 않는다. |
| 외부 신원 어댑터 | 인증 증거 검증, 장애 유형 구분 | 공급자 장애 시 보호 데이터 접근과 업무 저장을 중단한다. |
| 앱 세션과 가구 인가 | 세션 발급·종료·사용자 연결과 가구 범위 검증 | 세션 종료는 현재 로그인에 제한한다. 다른 가구의 데이터와 상태 정보를 차단한다. |
| 리마인더·저장소 | 시간 리마인더, 최초 회차와 원자적 저장·재시도 | 실패한 변경을 되돌리고 정상 재시작 시 동일 가구가 조회한다. |
| 로컬 운영과 자동 검증 | 요청 ID·로그·CI 결과 | 비밀을 노출하지 않고 실제 공급자·대상 환경 시험을 구분한다. |

공유 UI에서 반응형·접근성·현지화 요구사항을 확인한다. 키보드와 터치 검증에 화면 너비 변화, 입력 보존, 색상 이외의 상태 표현을 포함한다. 번역 리소스는 오류 코드와 응답 데이터를 바탕으로 화면에서 적용한다. ARM64 지원 확인과 테스트 우선·자동 검증의 증거는 구현 계획에서 추적한다.
