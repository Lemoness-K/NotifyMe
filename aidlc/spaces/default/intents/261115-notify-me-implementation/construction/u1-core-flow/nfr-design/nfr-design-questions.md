# U1 품질 설계 초안

## Consolidated Summary Confirmation

- **세션과 가구 접근.** 세션 발급은 브라우저의 일회용 로그인 요청과 그 요청 이후 로그인했음을 보여 주는 검증된 공급자 증거를 함께 확인한다. 이전 토큰이나 단순 토큰 갱신으로 세션을 재발급하지 않는다. 브라우저의 세션 쿠키 속성과 동일 출처·CSRF 방어를 발급·로그아웃·쓰기 검증에 포함한다. 한 세션을 닫아도 같은 사용자의 다른 유효한 세션은 유지한다.
- **인증 장애.** 잘못된 인증은 401, 공급자 검증을 일시적으로 완료할 수 없는 상태는 503으로 구분한다. 어느 경우에도 사용자·가구 데이터를 반환하지 않는다.
- **데이터와 성능.** SQLite의 짧은 트랜잭션, 가구 범위의 조회·페이지 처리와 작업 키를 사용한다. 최초 설정과 등록은 원자적으로 적용하고 정상 재시작 뒤 재조회한다. U1은 단일 노드로 검증하며 대상 성능의 합격 판단에는 승인된 Raspberry Pi 측정 조건과 예산을 사용한다.
- **로그와 자동 검증.** 로컬 운영 경로와 요청 ID를 사용하고 토큰·세션 비밀·리마인더 원문을 로그에 넣지 않는다. 기존 저장소에서 U1의 빌드·테스트 결과를 CI로 확인할 최소 작업과 담당을 코드 계획에 명시한다. 실행 증거를 남기고 외부 공급자 검증과 구분한다.
