# U4 Android 알림 상세 설계 질문

## Q-069 — 새 설치의 지오펜스 용량 초과

**상황.** Android를 처음 등록하거나 앱을 재설치할 때, 해당 사용자에게 이미 배정된 활성 장소 알림을 새 설치에 적용하면 지오펜스 한도를 넘을 수 있다. D-090은 등록된 설치에 대해 새 Reminder를 만들거나 담당자를 변경할 때의 저장 동작을 정한다. 기존 Reminder를 새 설치에 처음 반영할 때의 사용자 경험은 별도로 결정한다.

- **A (권장).** 웹·Android의 업무 기능과 시간 알림은 바로 사용한다. 새 설치의 장소 알림은 대기로 표시하고, 사용자가 이 설치에서 제외할 장소 알림을 골라 한도 안으로 줄이면 감지를 시작한다.
- **B.** 업무 기능과 시간 알림은 바로 사용한다. 새 설치는 정해진 우선순위대로 한도 내 장소 알림부터 자동으로 등록하고, 나머지 항목을 화면에 표시한다. 사용자가 나중에 활성 항목을 바꿀 수 있다.

어느 선택이든 가구의 Reminder와 다른 설치의 감지는 유지한다. A는 사용자가 의도한 장소 알림을 직접 고르게 하고, B는 일부 장소 알림을 즉시 사용할 수 있게 한다.

**영향.** D-044, D-090, FR4.8, PR-AC-068, US4.5, DS-011 및 설치 등록·동기화 계약.

[Answer]: A
