# U4 설치 설정과 알림 상태 화면

| 화면 | 입력과 동작 | 실패와 복구 |
| --- | --- | --- |
| 설치 상태 | 설치 이름, 시간 알림, 장소 감지, OS 알림·채널·정확 알람·위치 상태 | 연결 대기와 조회 오류를 다르게 표시한다. OS 권한은 해당 설정 경로를 연다. |
| 장소 용량 관리 | 현재 설치의 필요 슬롯·한도와 배정 업무를 페이지로 표시한다. 제외/복원 전 업무와 설치를 표시하고 확인받는다. | 서버 revision 충돌은 상태를 다시 읽고 사용자의 선택을 보존한다. 한도를 넘으면 대기 이유와 남은 조정량을 표시한다. |
| 업무 폼 | 기존 공유 폼과 업무 원문을 사용한다. 설치 용량 오류에서 입력을 보존하고 조정 화면으로 이동한 뒤 재시도한다. | 모바일 브라우저는 OS 기능 제한을 안내한다. 권한 거부가 기본 업무를 잠그지 않는다. |

색 이외의 상태 표기와 키보드·터치를 지원한다. 계정 locale, 기기 locale, 한국어 fallback 순서로 시스템 문구를 선택하고 사용자 원문은 보존한다.
