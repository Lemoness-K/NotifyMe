# U4 security-requirements

## Sources

`functional-spec.md`, `rules.md`, `requirements.md`, `contract-summary.md`, `technology-stack.md`를 적용한다.

## Requirements

- NFR1.1.4. 서버는 유효한 앱 세션에 설치 요청을 결합하고 앱 내부의 네이티브 예약에 필요한 자격은 플랫폼 보호 저장소에 둔다.
- NFR1.2.4. 모든 계획·이벤트와 제외 명령은 활성 가구 소속과 현재 설치 소유권을 서버에서 검사한다. 회수 커밋 뒤 동일 설치의 접근을 거절한다.
- NFR1.3.4. 서버·기기의 키에 가구·설치 및 세대를 결합한다. 회수·로그아웃은 해당 범위의 데이터와 예약을 제거하고 늦은 응답으로 되살리지 않는다.
- NFR1.4.4. 공급자 토큰 및 OS 자격 증명을 보호하고 네트워크·운영 로그·릴리스 소스에 노출하지 않는다.
- NFR2.1.4. 저장한 사용자 geofence 중심만 설치 계획에 사용한다. 이벤트는 비좌표 메타데이터를 감지부터 최대 30일 보관하고 사라진 데이터는 재업로드하지 않는다.
- NFR2.2.4. 잠금 화면의 공개 알림에는 업무 제목·본문 및 장소가 없다. 사용자 OS 설정이 최종 노출을 결정한다.
- NFR2.3.4. 가구 회수·로그아웃·보존 만료에 따라 동기화 데이터와 기기 이벤트를 정리한다. U5가 복구 사본을 소유한다.
