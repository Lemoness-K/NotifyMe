# 통합 테스트 안내

전체 Vitest 커버리지 실행에는 U1 SQLite·세션, U2 가구·설정·인가, U3 반복·검증·삭제, U4 설치 동기화와 U5 백업·격리 복원이 들어 있다. 각 Unit의 명령과 U3 HTTP 회귀를 분리해 실행하면 경계를 확인할 수 있다. 합성 계정과 작업별 임시 DB만 사용한다. Caddy의 테스트 인증서와 프로세스 준비 오류는 제품 응답의 불일치와 구분한다.

`npm run test:e2e`는 Playwright Chromium에서 U1 HTTPS 재시작, U2 가입과 설정 공유, U3 보관·삭제, U4 좁은 터치 화면 흐름을 실행한다. Android OS 예약이나 실제 FCM은 이 브라우저 시험 범위에 포함되지 않는다.

공용 스크립트 `npm run verify:u1`은 이름과 관계없이 타입 검사, 전체 앱 빌드, 프로젝트 전체 Vitest 커버리지, 브라우저 E2E를 모두 실행한다.
