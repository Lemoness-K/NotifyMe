커밋 `1e031d095d8435759a2db9699a8a9f1906376f25`에서 타입 검사와 앱 빌드가 통과했다. 32개 파일의 Vitest 214개 및 실제 Chromium의 Playwright 4개가 통과했다. 라인 커버리지는 87.16%로 80% 기준을 충족했다. 로컬 Android 스케줄 코어 JVM 테스트 16개 및 동일 커밋의 SDK 앱 테스트와 APK 빌드도 통과했다. [GitHub 앱 CI](https://github.com/Lemoness-K/NotifyMe/actions/runs/45116211453) · [GitHub Android CI](https://github.com/Lemoness-K/NotifyMe/actions/runs/45117506039)

검증 범위는 단위·합성 통합·실제 브라우저 검증을 포함한다. 실제 Raspberry Pi 성능, 실제 Android OS 연동과 백업 보존의 운영 경계에 관한 증거가 남아 있다. 배포 준비 완료 판정은 보류한다.

## 검증 범위와 준비 상태

웹 빌드와 웹 자동화 검증은 개발 환경에서 재현할 수 있다. 검증 범위는 HTTP, 저장소, 합성 인증·백업 통합, Chromium, Android JVM 및 SDK 빌드다. 프로젝트 커버리지 기준은 전체 측정 소스의 라인 80%이며 검증 결과는 Unit별 실행과 전체 커버리지를 구분한다.

배포 가능 여부에는 실기기·운영 측정 증거와 이미 수용한 U2·U4·U5 후속 항목이 남아 있다. [테스트 실행 결과](test-results.md)
