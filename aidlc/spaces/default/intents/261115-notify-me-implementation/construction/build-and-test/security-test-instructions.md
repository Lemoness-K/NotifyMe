# 보안 테스트 안내

기존 합성 테스트로 현재 세션과 가구 인가, 초대 비밀의 저장·응답 경계, 내부 운영 소켓과 Caddy 공개 경계, 복구 재인증, 백업과 삭제 재적용을 확인한다. 합성 동작 검증은 `tests/u1/http.test.ts`, `tests/u2/http.test.ts`, `tests/u3/http.test.ts`, `tests/u5/{backup,runtime}.test.ts`에 있다. 운영 환경이나 외부 시스템에는 연결하지 않는다.

Android 진단에는 실제 기기 인수 증거가 필요하다. 서버 동기화 확인 이후 위치 이벤트 잔류와 만료 백업의 물리 정리 범위는 독립 리뷰에서 각각 확인한 보완 항목이다.

결과에 실제 사용자 정보, 자격 증명, 백업 키, 쿠키를 넣지 않는다.
