# 성능 테스트 안내

대상은 DS-014에서 승인한 Raspberry Pi, 데이터 규모, 동시 요청 수, 워밍업 및 관측 구간이다. 대상 환경과 최대 메모리·저장 쓰기 예산 확정 후 실행한다. 이 단계의 개발 호스트 시간이나 테스트 실행 시간은 제품 합격값으로 사용하지 않는다.

- U1 로그인 이후 목록·상세, U2 구성원·설정, U3 할 일·상세·이력, U4 설치 동기화·용량 조회, U5 백업 중 보호 API의 응답 p95를 각각 측정한다. 기준은 500ms 이하이다.
- 같은 부하에서 RSS 최대값과 저장장치 쓰기 증가량을 수집한다. 정상 상태와 반복·삭제·백업 동시 작업 구간을 구분한다.
- 대상과 승인된 예산이 준비되면 Performance Validation에서 환경, 작업 부하, 시계, 원자료, 표본 수와 판정을 남긴다.
