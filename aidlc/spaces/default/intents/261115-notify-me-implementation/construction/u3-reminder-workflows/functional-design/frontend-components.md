# U3 공유 화면 설계

| 화면 | 상태 및 행동 |
| --- | --- |
| 할 일 | 기본 내 할 일, 내가 요청한 일, 가구 전체. 이름이 들어가는 폭에서 직접 버튼을 제공하고 좁은 폭에서는 현재 선택이 표시된 메뉴로 전환한다. 버킷과 상태를 텍스트로 표시한다. |
| 등록·수정 | 요청자·담당자와 TIME/LOCATION 선택, 반복 주기·주 기준·종료일, 완료 검증 선택을 입력한다. 편집 범위와 표시·일정 시간대를 안내하고 잘못된 입력은 유지한다. |
| 상세·회차 | 서버의 현재 회차와 revision을 사용하며 `allowedActions`에 따라 완료·취소·건너뛰기·검증 승인/거절·철회를 제공한다. 대기 건수에서 필터한 회차 모음을 열어 기준 회차가 아닌 이전 검증 요청도 처리한다. |
| 완료 검증 | 적격 검증자를 선택한다. 검증 대기에서 제출자에게만 철회를, 현재 지정 검증자에게만 승인·거절을 제공한다. 회수로 미완료가 되면 새 검증자를 선택하고 다시 요청할 수 있다. |
| 이력 | 현재 담당 기준과 가구 전체를 전환한다. 업무 수명주기·회차 상태는 고정된 흐름과 현재 강조로 보인다. |
| 보관함 | 보관 시각 최신순이며 상세·복원·영구 삭제로 이동한다. 삭제는 대상 제목과 복구 불가 확인을 제공한다. |

할 일·이력·보관함은 주요 내비게이션에서 바로 열 수 있고 좁은 화면에서는 하단에 둔다. 로딩·빈 결과·오류의 안내와 키보드·터치 접근을 검증한다. 자동 번역은 시스템 리소스에 한정한다. Android OS 작업은 기능 어댑터로 연결하며 해당 기능이 없는 웹에서 일반 업무를 계속 사용할 수 있다.
