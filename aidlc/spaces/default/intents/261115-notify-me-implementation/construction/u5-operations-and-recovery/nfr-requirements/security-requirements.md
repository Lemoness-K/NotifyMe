## Requirements

- NFR1.1.5. 복구·백업 명령은 전용 운영 주체로 제한한다. 운영 웹 세션은 관리자 명령의 인가로 사용하지 않는다.
- NFR1.2.5. 재개 전 기존 가구 소속·역할의 조회 격리를 합성 계정으로 확인한다.
- NFR1.3.5. 확정 삭제 재적용은 원장과 대상의 범위를 일치시킨다. 다른 가구의 동명 데이터 등 음성 사례에서 변경 건수는 0이어야 한다.
- NFR1.4.5. 백업·원장 증거 키, 패키지 자격과 운영 세션은 로그·CLI 인자·공개 아티팩트에 노출하지 않는다.
- NFR2.1.5. 인증 암호화에 실패하거나 키·인증 태그가 다른 사본은 공개 복구에 사용하지 않는다.
- NFR2.3.5. 백업 보관은 최대 30일이다. 증거 바닥 아래 후보, 만료 후보와 두 항목이 서로 어긋난 상태에서는 재개하지 않는다.
