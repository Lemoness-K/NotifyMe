# U2 웹 화면 연결

| 화면 | 사용자 흐름 | 상태 및 API |
| --- | --- | --- |
| 초대 관리 | Admin이 대상 이메일을 입력하고 최초 응답에서 링크를 복사·공유한다. | 발급 응답이 유실됐으면 기존 초대를 취소한 뒤 새 링크를 발급한다. 발급 실패 시 입력을 유지하고 비밀을 운영 로그에 쓰지 않는다. |
| 초대 수락 | 링크에서 안내를 읽고 Google 계정을 고른 뒤 수락을 명시적으로 누른다. | GET은 가입 상태를 바꾸지 않는다. 잘못된 계정 또는 만료에는 가입 실패를 안내한다. 성공 후 일반 로그인과 가구 화면으로 이동한다. |
| 구성원 관리 | 활성 소속 목록과 현재 역할을 표시하고, Admin에게 역할 변경·제거 동작을 제공한다. | 마지막 Admin의 변경은 후임 선택을 요구한다. 제거 확인에 대상과 영향 범위를 표시하고 revision 충돌 시 최신 상태를 읽는다. |
| 설정 홈 | 가구·개인·이 설치 링크를 구분한다. Reminder 전용 설정은 해당 Reminder 화면에서 연다. | 설정 카탈로그 정의로 범위와 검증을 안내한다. 설치에서만 지원되는 항목은 U4 연동 후 해당 OS 화면을 연다. |
| 개인 설정 | UI 언어와 표시 시간대를 선택한다. | 개인 설정 API를 읽고 저장한다. 지원되지 않는 기존 locale은 fallback하며 저장 성공 시 화면 문구를 즉시 바꾼다. |
| 가구 정책 | Admin이 기본 시간대·반경·시간 상한·주간 기준을 편집한다. | 범위를 이탈한 장소 Trigger가 조정될 수 있음을 저장 전에 안내한다. 실패 시 입력을 보존한다. |

주요 동작은 터치와 키보드를 지원하고, 상태와 오류가 색으로만 구분되지 않게 한다. 각 화면은 로딩·빈 상태·오류를 구분하고 필드별 검증을 보여준다. 변경 요청은 공통 작업 키를 사용한다. 역할 변경·구성원 제거·설정 저장은 revision도 사용한다. 일시적인 API 오류의 `Retry-After`를 읽고 같은 변경의 결과가 불확실하면 키와 입력을 유지한다.
