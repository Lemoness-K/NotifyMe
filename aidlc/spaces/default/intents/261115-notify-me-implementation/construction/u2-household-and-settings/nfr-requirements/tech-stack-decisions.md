# U2 기술 기준과 검증 요구사항

## Sources

U2 `functional-spec.md`와 `rules.md`, Inception `requirements.md`와 `contract-summary.md`, CodeKB `technology-stack.md`를 근거로 한다. 현재 실행 스택은 U1의 `package.json`, `package-lock.json` 및 `docs/u1-local-run.md`에서 확인했다.

## Requirements

| ID | 요구사항 | 확인 방법 |
| --- | --- | --- |
| NFR6.1.2 | 가구·개인 설정, 초대, 구성원 화면을 가용 뷰포트에 맞춰 재배치한다. | 여러 대표 크기와 폭 변경을 사용한다. 고정 최소 너비를 제품 기준으로 두지 않는다. |
| NFR6.2.2 | 핵심 가구 작업의 입력, 링크 복사, 역할 후임 선택과 오류 복구는 키보드와 터치로 조작한다. | 브라우저에서 가로 넘침, 초점 순서, 조작 가능 상태를 확인한다. |
| NFR6.3.2 | 초대·구성원·설정 상태는 색상과 독립적으로 전달한다. | 텍스트·오류와 접근 가능한 이름을 확인한다. |
| NFR6.4.2 | 가구·개인 설정은 Android 위치·알림 권한 없이 동작한다. | 브라우저 환경과 권한 거부를 합성한 환경에서도 기본 경로가 동작한다. |
| NFR7.1.2 | UI와 시스템 문구는 한국어·영어 키와 리소스를 사용하며 새 locale을 업무 규칙과 분리한다. | 같은 라우트에서 두 언어를 테스트하고 메시지 키 격리를 확인한다. |
| NFR7.2.1 | 저장된 지원 사용자 언어를 기기 선호보다 우선하며 둘 다 없거나 미지원이면 한국어로 표시한다. | 동일 계정의 서로 다른 두 클라이언트, 미저장, 미지원 저장값을 각각 확인한다. |
| NFR7.3.2 | 날짜·시각·수치·복수형은 현재 사용자 locale과 표시 시간대로 표시한다. | 형식이 바뀌어도 원본 instant와 일정 zone이 유지된다. |
| NFR7.4.2 | 서버 오류와 상태 enum은 locale에 중립적이며 화면만 번역한다. | 언어 전환 후 동일 요청의 구조화 코드를 비교한다. |
| NFR7.5.2 | 기존 Reminder 제목·설명의 원문을 locale 변경 시에도 보존한다. | 같은 기존 업무를 두 locale로 조회한다. |
| NFR8.1.2 | U1의 공유 웹과 API에 추가하며 도메인은 Android SDK를 직접 의존하지 않는다. | 웹과 서버 빌드 및 향후 설치 어댑터 계약을 검사한다. |
| NFR8.2.2 | U1의 Node 24·NestJS·Prisma 7·SQLite 네이티브 이용을 유지하고 ARM64 및 lockfile을 확인한다. | 개발 환경 native 빌드와 대상 Pi의 후속 검증을 구분한다. |
| NFR9.1.2 | 변경 동작에 대해 TDD 순서를 적용한다. | Red와 Green 결과와 실행 명령을 남긴다. |
| NFR9.2.2 | 기존 U1 회귀 및 U2 신규 규칙, 실제 저장소와 브라우저 경로를 자동화한다. | 실제 외부 계정은 승인된 비운영 환경에서 별도로 시험한다. |
| NFR9.3.2 | 전체 라인 커버리지 80%를 유지한다. | 기존 커버리지 기준과 보고서로 확인한다. |
