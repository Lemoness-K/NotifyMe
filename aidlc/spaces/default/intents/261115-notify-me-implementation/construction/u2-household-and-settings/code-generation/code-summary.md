# U2 구현 결과

## Summary

- 초대 발급·상태 목록·취소와 검증된 Google 계정의 수락을 추가했다. CSPRNG 비밀은 해시로 저장하고 링크 원문은 첫 응답에만 포함한다. 유실된 응답의 재시도는 기존 초대의 안전한 식별 정보로 복구한다.
- 동일 가구에서만 Admin 명령을 허용한다. 마지막 Admin 인계·기존 소속 변경과 실제 U1 배정 종료를 같은 트랜잭션에서 적용하며 공유 업무와 감사 이력을 보존한다.
- 네 가지 설정 범위를 카탈로그에 정의했다. 가구 정책과 계정 locale·표시 시간대를 해당 소유자의 저장 위치에 유지한다. 계정 화면 접근에는 계속 유효한 앱 세션을 사용한다.
- 웹에 초대, 구성원, 가구, 개인 설정 화면을 추가하고 한국어·영어 리소스를 연결했다. 기존 목록 조회와 새 U2 요청은 유효한 `Retry-After`를 적용한다.
- `prisma/migrations/202611190001_u2/migration.sql`은 U1 DB에서 기존 데이터를 유지한다. 실제 U1 배정을 비활성화하며 U3 업무 및 U4 설치 효과가 연결될 트랜잭션 경계를 제공한다. 운영 변수와 로컬 시연은 `docs/u2-local-run.md`에 있다.

데이터 모델·저장소·규칙·HTTP 단계의 실패를 먼저 확인한 뒤 구현으로 통과시켰다. 웹의 초기 DOM 회귀가 실패한 후 화면을 작성했다. 종단 시나리오는 화면 구현 후 완성하여 Green을 확인했다. 이후 초대 발급 복구 경로의 중복 POST 재현을 추가하고 같은 경로가 취소 전에는 다시 발급하지 않는지 확인했다.

## 현재 구현과 문서 이력 재검증

- U2 구현 커밋 `8fc86d3`의 AI-DLC 기록 외 변경 31개 경로가 현재 [소스 매니페스트](source-manifest.json)의 31개 경로와 일치한다. 해당 커밋에는 U2 로컬 실행 안내가 포함된다.
- [공통 문서 변경 이력](../../code-generation/document-provenance.md)을 Git으로 대조했다. 요구사항 분석에서 변경된 문서 5개는 `7022058` 이후 동일하며 현재 SHA-256도 Code Generation 기준선과 일치한다. 마스터 설계, 제품 요구사항, 알림·운영 문서와 공통 결정 등록부의 후속 변경은 U3~U5 구현 커밋에서 확인했다.
- 초기 구현의 테스트 우선 검증 증거는 위에 보존했다. 이번 재검증에서는 기존 테스트를 그대로 실행했다.

| 검사 | 현재 결과 |
| --- | --- |
| `npm exec -- vitest run tests/u2/` 첫 실행 | 6개 파일에서 53개 통과, 1개 실패. Caddy가 설정을 적용한 뒤 테스트의 HTTPS 준비 확인을 완료하지 못했다. |
| 승인된 `npm run verify:u1` 첫 실행 | 타입 검사와 빌드 통과. Vitest 211개와 U2 Caddy 통합 테스트가 통과했고, 라인 커버리지는 87.26%였다. 브라우저는 U1·U2·U4 3개가 통과했고 U3 1개가 90초 제한으로 실패했다. U2 브라우저에서 초대 수락, 계정 표시 설정 공유, 소속 회수를 확인했다. |
| 승인된 `npm run verify:u1` 재실행 | 종료 코드 0. 타입 검사와 빌드, Vitest 32개 파일의 211개 시험, Playwright 4개가 모두 통과했다. 라인 커버리지는 87.26%(2,893/3,315)로 80% 기준을 충족했다. U2 브라우저는 29.5초, U3 브라우저는 10.7초였다. |
| U2 Caddy 사례 단독 재실행 | `npm exec -- vitest run tests/u2/http.test.ts -t 'uses Caddy ingress'`로 해당 통합 시험 1개가 통과했다. |

실행 사이에 제품 코드, 테스트, 시간 제한을 변경하지 않았다.

## Remaining verification

- 실제 Google/Firebase 로그인, 목표 Raspberry Pi, 원격 GitHub Actions 및 DS-014 성능·자원 측정은 이 로컬 실행에서 검증하지 않았다.
- 인프라 자동 추적 검사에서 앞선 NFR 설계 Markdown의 상세 ID를 인식하지 못했다. 인프라 리뷰에서 연결 12개를 수동 대조했다. 코드 추적은 별도 실행한다.
- 활성·보관 장소 조건과 Android 설치 효과는 각 생산 데이터가 추가되는 U3·U4에서 통합한다. U2는 실제 U1 배정 종료와 정책 변경의 트랜잭션 경계를 검증한다.
