## Q-057 — 장소 시간 직접 입력의 허용 범위

- 맥락: `DWELL(N)`과 `AFTER_EXIT(N)`은 5·10·15·30·60분 빠른 선택과 직접 입력을 제공하고 기본값은 10분이다(`D-082`). 직접 입력의 최소·최대 범위는 아직 정하지 않았다.
- 질문: 분 단위 직접 입력을 어느 범위까지 허용할까요?
- 추천: 1~1,440분 정수를 허용한다. 1분의 짧은 조건부터 하루 뒤 알림까지 지정할 수 있고, 지나치게 긴 값을 막는다.
- 선택지: 1~1,440분(추천); 1~180분; 1~10,080분(7일).
- 답변: 기본 최대 60분으로 시작하고 가구 설정에서 변경할 수 있게 한다. 직접 입력은 1분부터 현재 가구 상한까지 허용한다.
- 결정: `D-085`, `F-SET-006`, `PR-AC-066`.
- 상태: 해결. 상세 입력·오류 검증은 `DS-006`, 설정 화면은 `DS-007`에 반영한다.

## Q-058 — 주간 반복에서 주 경계와 첫 주의 회차

- 맥락: N주 간격은 첫 예정 회차가 속한 주를 기준으로 한다(`D-083`). 구현을 위해 현지 주의 시작일과 첫 주에서 반복 시작일보다 앞선 선택 요일을 어떻게 다룰지 정해야 한다.
- 질문: 주간 반복의 첫 주와 이후 N주 주기를 어떻게 계산할까요?
- 추천: 반복 규칙 시간대의 월요일 시작 주를 사용하고, 첫 주에는 시작일 이후(시작일 포함)의 선택 요일만 회차로 만든다. 이후 주는 첫 예정 회차가 속한 주를 0주로 세어 N주 간격을 적용한다. ISO 주차 번호의 짝·홀수는 사용하지 않는다.
- 선택지: 월요일 시작 현지 주, 첫 주는 시작일 이후 요일만 포함(추천); 일요일 시작 현지 주, 첫 주는 시작일 이후 요일만 포함; 첫 예정 회차 시각부터 7일씩 이어지는 구간.
- 답변: 주 기준은 가구 설정으로 고를 수 있게 하고 월요일 시작을 기본값으로 한다. 일요일 시작과 ISO 8601도 선택지로 둔다.
- 결정: 첫 주는 시작일을 포함해 이후의 선택 요일만 만들고, 설정값은 새 반복 규칙에 저장해 기존 규칙의 일정을 바꾸지 않는다. ISO는 월요일 시작·ISO week-year 표기 기준을 사용한다. 전역 주차 홀짝을 쓰지 않으므로 현재 N주 반복 회차 날짜는 월요일 convention과 같고, 최초 예정 회차 주를 anchor로 유지한다(`D-086`).
- 상태: 해결. 설정 카탈로그는 `DS-007`, 주간 계산 예시는 `DS-010`에 반영한다.

## Q-059 — 주간 반복 규칙 수정 후 anchor 처리

- 맥락: 반복 규칙은 `이번 회차만`, `이번 회차와 이후 회차`, `전체 반복` 범위로 수정할 수 있다(`D-063`). 규칙의 요일이나 N주 간격을 바꿀 때 주간 anchor를 유지할지 다시 정할지 구체화하지 않았다.
- 질문: 주간 반복의 요일·간격을 수정하면 이후 반복의 기준 주를 어떻게 정할까요?
- 추천: 시리즈의 첫 예정 회차가 속한 주를 유지한다. 규칙 변경만으로 격주 주기가 임의로 앞뒤 이동하지 않으며, 시작일 자체를 바꾼 경우에만 새 시작일을 기준으로 다시 계산한다.
- 선택지: 첫 예정 회차의 기준 주 유지(추천); 수정이 적용되는 첫 회차부터 새 기준 시작; 사용자가 수정한 날짜부터 새 기준 시작.
- 답변: 요일·간격 변경은 최초 예정 회차가 속한 주 anchor를 유지하고, 시작일 자체를 바꾼 경우에만 새 시작일·달력 convention·선택 요일에서 처음 만들어질 회차를 기준으로 anchor를 다시 계산한다.
- 결정: `D-087`.
- 상태: 해결. edit scope별 재생성 규칙과 결정적 예시는 `DS-010`에 반영한다.

## Q-060 — 이력 범위 전환의 다음 방문 기본값

- 맥락: 이력 화면은 담당 Reminder의 기록을 기본으로 보여주고, 가구 전체 이력으로 전환할 수 있다(`D-080`). 사용자가 가구 전체 보기로 바꾼 뒤 다시 이력 화면을 열 때 선택을 기억할지는 정하지 않았다.
- 질문: 이력 화면을 다시 열면 조회 범위를 어떻게 설정할까요?
- 추천: 매번 담당 Reminder 범위로 시작한다. 넓은 조회 범위가 기본값으로 남지 않고 `D-080`의 기본 동작도 분명하다.
- 선택지: 매번 담당 Reminder 범위로 시작(추천); 마지막 선택을 계정에 저장; 앱을 닫기 전까지만 마지막 선택 유지.
- 답변: 이력 화면을 열 때마다 담당 Reminder 범위로 시작한다.
- 결정: `D-088`. 가구 전체 범위 선택은 현재 화면 세션에서만 유지한다.
- 상태: 해결. 화면 진입·복귀 동작은 `DS-005`에 반영한다.

## Q-061 — 보관함 기본 정렬

- 맥락: 보관함에는 복원 가능한 Reminder가 남고, 보관 중인 반복 Reminder는 일시 중지된다(`D-032`, `D-033`). 보관함의 기본 정렬은 아직 정하지 않았다.
- 질문: 보관함을 열었을 때 항목을 어떤 순서로 보여줄까요?
- 추천: 가장 최근에 보관한 Reminder를 위에 둔다. 방금 보관한 항목을 쉽게 찾고 복원할 수 있다.
- 선택지: 최근 보관순(추천); 제목 가나다·알파벳순; 최근 수정순.
- 답변: 최근 보관순으로 표시한다.
- 결정: `D-089`; 같은 보관 시각 항목의 보조 정렬은 `DS-005`에서 정한다.
- 상태: 해결. 보관함 목록 동작은 `DS-005`에 반영한다.
