## Q-065 — 첫 실행의 locale 선택

- 맥락: 기존 승인 기준은 저장된 locale이 없을 때 `ko-KR`을 사용했다. 한국어·영어가 모두 지원되는 MVP에서 저장된 사용자 선택이 없을 때 기기 언어를 자동으로 적용할지 정하지 않았다.
- 질문: 첫 실행에 저장된 언어 선택이 없을 때, 지원되는 기기 언어를 자동 적용할까요?
- 선택지:
  - 제안 승인 — 지원되는 기기 locale을 첫 실행에 자동 선택하고 관련 기준 문서와 정식 요구사항을 갱신한다.
  - 제안 거절 — 저장 선택이 없으면 `ko-KR`을 사용한다.
  - 제안 보류 — 이번 요구사항에는 넣지 않고 현재 승인된 기본값을 유지한다.
- 답변: 제안 승인.
- 결정: 유효한 저장 사용자 locale은 기기 locale보다 우선한다. 유효한 저장값이 없으면 지원되는 기기 locale(`ko-KR`, `en-US`)을 사용하고, 기기 locale이 지원되지 않으면 `ko-KR`로 fallback한다.
- 결정 ID: `D-093`.
- 질문 상태: 해결.
