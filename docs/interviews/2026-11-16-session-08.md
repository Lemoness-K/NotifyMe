## Q-063 — 선택적 완료 검증의 MVP 범위

- 맥락: 이번 의도서 Q1·Q10~Q14는 Reminder별 선택적 완료 검증을 요청한다. 현재 마스터 설계 §6~§7과 제품 요구사항 §2~§3·§6에는 이 흐름이 없다. 동시에 이번 작업은 현재 문서에 정의된 MVP만 포함한다는 Q12 답변이 있다.
- 질문: 담당자가 완료를 표시한 뒤 별도 가구 구성원이 확인하는 선택적 완료 검증을 이번 MVP에 포함할까요?
- 추천: 이번 MVP에 포함한다. 사용자가 검증 흐름과 거절·미응답 동작을 구체적으로 요청했으므로, 기존 문서 기준선에 승인된 범위 추가로 기록하고 마스터·요구사항·추적표를 갱신한다.
- 선택지:
  1. 이번 MVP에 포함하고 기존 기준 문서를 갱신한다. (추천)
  2. 이번 MVP에서는 제외하고 후속 단계로 미룬다.
- 영향 ID: `D-013`, `F-REM-001`, `F-REM-005`, `F-HIS-001`, `F-SET-005`, `PR-AC-003`, `PR-AC-014`, `DS-001`, `DS-004`, `DS-009`.
- 답변: A. 이번 MVP 포함 (Recommended).
- 결정: 이번 작업 MVP에 선택적 완료 검증을 추가한다. 기존 문서 MVP의 범위 변경은 요약 확인 후 기준 문서에 반영한다.
- 결정 ID: 요약 확인 뒤 부여.
- 상태: 답변 접수, 요약 확인 대기.
