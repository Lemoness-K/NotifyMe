# ADR-013: 담당자 전용 알림 전달

- 상태: 승인
- 날짜: 2026-11-08
- 관련 결정: `D-010`, `D-012`, `D-013`, `D-044`, `D-045`, `D-073`
- 관련 요구사항: `PR-AC-013`, `F-NOT-009`

## 맥락

Reminder에는 담당자를 여러 명 지정할 수 있고 가구 구성원은 모두 업무를 조회·수정·완료할 수 있다.
알림까지 모든 구성원에게 보내면 담당자가 아닌 구성원에게도 불필요한 알림이 갈 수 있다.

## 결정

- 알림 수신자는 해당 Reminder의 활성 Assignment에 지정된 사용자로 제한한다.
- 각 담당자의 알림 가능한 활성 installation에 시간 알림을 예약·전달한다. 한 사용자가 여러 활성
  installation을 쓰는 경우 각각을 대상으로 한다. Android OS 채널이 꺼져 있거나 표시 권한이 없고,
  그 설치에서 전달할 수 없는 경우 해당 설치만 제외하고 상태를 표시한다. 채널 on/off, 표시·소리와
  방해 금지는 OS가 관리하며 앱 UserSettings에 복제하지 않는다(`D-073`).
- 장소 알림은 각 담당자의 알림 가능한 installation에만 geofence를 등록한다. 해당 설치가 조건을
  인식하면 로컬 알림을 표시한다. 권한이 없는 설치는 `D-044`에 따라 알림 불가 상태를 보이며 다른
  담당자의 기기는 계속 독립적으로 동작한다.
- 담당자가 아닌 household member는 알림 recipient가 아니지만 Reminder CRUD와 Occurrence 완료 권한을
  유지한다(`D-010`). 한 구성원이 완료하면 전체 Occurrence가 완료되고 다른 담당자의 예약 알림·지오펜스를
  취소한다(`D-013`, `D-041`).

## 결과

- 사용자 알림은 실제 수행 담당자에게만 전달된다.
- 조회·수정·완료 권한과 알림 수신 자격은 별개로 유지된다.
- NotificationIntent의 사용자 recipient와 기기별 DeliveryAttempt를 분리해 여러 기기와 push provider를
  지원한다.
