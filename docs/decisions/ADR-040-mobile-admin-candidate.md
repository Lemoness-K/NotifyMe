# ADR-040 모바일 최초 관리자 후보 권한

## Context

`Q-071` Tailscale 접근 범위에 따라 현재 배포의 최초 설정 HTTPS 주소에는 운영자만 도달한다. `D-099` 모바일 최초 등록은 사용자가 Google 계정을 확인하고 취소할 기회를 제공한다.

## Decision

검증된 Google/Firebase 계정의 최초 후보를 10분 동안 예약한다. 범위가 설정으로 한정된 쿠키와 현재 인증이 같은 후보일 때만 확인하거나 취소할 수 있다. 취소가 먼저 적용되면 권한을 즉시 해제한다. 창 닫기나 재인증으로 유효기간을 늘리지 않는다. 등록이 커밋된 경우 같은 계정의 재시도는 기존 가구로 이어진다.

운영자 전용 Tailscale 내부 HTTPS 배포에는 별도 코드나 토큰 입력을 추가하지 않는다. 접근 권한을 운영자 외로 넓히거나 공개 인터넷에 배포하기 전에 사전 승인 또는 운영자 증명 방식을 별도로 결정하며 그때까지 공개 최초 등록을 사용하지 않는다. [보안 설계](../07-security-and-privacy.md#최초-관리자-등록).

## Consequences

Google 인증 성공만으로 업무 권한을 얻을 수 없다. 후보 자신의 계정은 화면에 표시하고 다른 요청자에게 공개하지 않는다. 배포 검증은 실제 Android Chrome 모바일 데이터 흐름과 후보 권한 테스트를 분리한다.

## Alternatives Rejected

- 최초 인증 즉시 ADMIN을 생성하면 계정 확인과 취소가 불가능하다.
- 운영자만 도달하는 설치에 별도 수동 코드를 매번 요구하면 이번 변경의 모바일 독립 설정 목표를 저해한다.
