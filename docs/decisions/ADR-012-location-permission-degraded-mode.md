# ADR-012: 백그라운드 위치 권한이 없는 설치의 동작

- 상태: 승인
- 날짜: 2026-11-08
- 관련 결정: `D-005`, `D-019`, `D-044`
- 관련 요구사항: `PR-AC-009`, `NFR-UX-004`

## 맥락

앱이 보이지 않는 동안 장소 알림을 받으려면 Android 백그라운드 geofence 사용이 필요하다. 사용자가
권한을 거부할 수 있으므로 이 한 설치의 권한 상태가 리마인더 생성이나 다른 구성원의 기기 상태를
막지 않게 해야 한다.

## 결정

- 백그라운드 위치 권한을 요청하기 전에 장소 조건이 앱이 닫혀도 동작하도록 필요한 이유를 설명하고,
  Android 시스템 권한 요청 또는 설정 화면으로 안내한다.
- 사용자가 권한을 거부해도 LOCATION Reminder와 Trigger는 저장한다. Reminder를 생성하거나 수정하는
  흐름을 막지 않는다.
- 권한이 없는 설치에는 `LOCATION_PERMISSION_REQUIRED` 상태와 Android 설정 바로가기를 보여준다.
  해당 설치의 지오펜스는 권한이 허용될 때까지 등록하지 않는다.
- 권한 상태와 capability는 `DeviceInstallation`별로 저장·표시한다. 다른 구성원 기기의 지오펜스와
  알림은 권한 거부의 영향을 받지 않는다.
- 사용자가 설정에서 권한을 허용하면 앱은 기기 상태를 다시 읽고 해당 installation에 할당된 활성
  geofence만 reconcile해 등록한다. OS 설정을 앱에서 강제로 변경하지 않는다.

## 결과

- 권한을 허용하지 않은 사용자는 장소 알림을 받을 수 없는 이유와 해결 경로를 알 수 있다.
- Reminder와 공유 업무 목록은 권한 거부 중에도 계속 사용할 수 있다.
- 서버의 Trigger 정의와 각 기기의 실제 등록 상태를 분리하고 권한 상태를 기기 capability로 취급한다.
