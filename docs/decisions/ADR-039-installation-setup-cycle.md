# ADR-039 설치 주기와 최초 등록 자격

## Context

`D-074` 서버 CLI는 존재하는 가구로 등록 여부를 확인했다. `D-099` 모바일 최초 등록의 경우 가구가 없거나 DB를 일시적으로 읽을 수 없어도 새 등록을 열면 안 된다.

## Decision

명시적인 신규 설치 준비가 보호된 운영 기록과 활성 DB 식별자를 결합한다. 새 설정 주기에서만 등록을 허용하고, 후보 확인 진행을 보호된 기록에 먼저 쓴다. 같은 활성 DB의 트랜잭션이 가구·ADMIN·완료를 함께 커밋한 뒤 운영 기록을 봉인한다. 커밋 여부를 확정할 수 없는 중단은 차단한다. 커밋이 확인되면 재기동 후에도 등록은 닫힌다.

관리형 복원은 이전 세대의 후보를 폐기하고 활성 기록을 바꾼다. 가구 종료는 새 주기를 발급할 수 없다. 운영자는 의도적인 재설정이 필요할 때 기존 데이터를 보존한 채 승인된 새 인스턴스를 준비한다. [설치·복원 경계](../02-domain-and-data-design.md#41-user-authidentity-household-membership).

## Consequences

가구와 첫 관리자는 각 설정 주기마다 한 번만 확정할 수 있다. 불명확한 설치 상태에서 등록을 닫아 가용성보다 권한 보호를 우선한다. 기존 DB는 원래 로그인과 초대를 유지한다.

## Alternatives Rejected

- 가구가 없을 때 자동 등록을 허용하면 종료·복원·DB 장애를 구분하기 어렵다.
- 등록 자격을 DB 안에만 저장하면 이전 스냅샷에 의해 등록 가능 상태까지 복원될 수 있다.
