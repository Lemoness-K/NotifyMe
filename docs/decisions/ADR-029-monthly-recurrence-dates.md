# ADR-029: 월간 반복의 특정 날짜와 말일

- 상태: 승인됨
- 날짜: 2026-11-09
- 결정: `D-061`
- 관련 결정: `D-030`, `D-060`
- 관련 기능: `F-REC-003`
- 관련 요구사항: `PR-AC-047`
- 관련 문서: [마스터 설계](../00-master-design.md), [제품 요구사항](../01-product-requirements.md), [도메인·데이터 설계](../02-domain-and-data-design.md), [알림·스케줄링](../04-notification-and-scheduling.md)

## 배경

월간 Reminder에서 “매월 마지막 날”과 “매월 30일”은 서로 다른 규칙이다. 30일 반복을 2월 말에
자동 보정하면 사용자가 선택한 날짜의 의미가 달라진다. 반면 실제 월말 정산 같은 일은 짧은 달에도
해당 달의 마지막 날짜에 실행할 수 있어야 한다.

## 결정

- 월간 반복은 `SPECIFIC_DAY` 또는 `LAST_DAY` 모드 중 하나를 가진다.
- `SPECIFIC_DAY`는 1~31 사이의 날짜를 저장한다. 대상 월에 그 날짜가 없으면 해당 월에는 Occurrence를
  생성하지 않고 다음 원래 반복 일정으로 넘어간다. 월말로 보정하지 않는다.
- `LAST_DAY`는 매달 달력의 실제 마지막 날짜에 Occurrence를 생성한다. 2월은 28일 또는 29일, 30일인
  달은 30일, 그 밖의 달은 해당 달의 마지막 날을 사용한다.
- 월초는 별도 모드가 아니다. 매월 1일 반복은 `SPECIFIC_DAY(1)`로 표현한다.
- 존재하지 않는 특정 날짜의 월에는 회차를 만들지 않고 알림도 예약하지 않는다. 이 월을 건너뛴 것만으로
  이전 `PENDING` 회차를 종료하지 않는다. 다음 실제 반복 시각에 도달하면 기존 반복 미완료 규칙을 적용한다
  (`D-030`).
- 반복 간격은 원래 규칙에 유지한다. 없는 날짜를 보정하거나 건너뛰었다고 이후 월간 일정의 기준점을
  이동하지 않는다.

## 결과

- UI는 날짜 선택과 `매월 말일` 선택을 구분한다. 특정 날짜 1일로 월초 반복을 설정할 수 있다.
- RecurrenceRule은 `month_day_mode`와 `day_of_month`를 분리해 저장한다. `LAST_DAY`에서는
  `day_of_month`를 비우고, `SPECIFIC_DAY`에서는 1~31의 날짜를 저장한다.
- 발생하지 않는 월간 회차는 Occurrence·DeviceTrigger·알림을 만들지 않는다.

## 구현 시 확인 사항

- `SPECIFIC_DAY(30)`은 2월에 발생하지 않고, 일반 연도의 3월 30일에 다시 발생한다.
- `SPECIFIC_DAY(31)`은 31일이 없는 달을 건너뛰며, 31일이 있는 달에는 31일에 발생한다.
- `LAST_DAY`는 매달 실제 마지막 날짜에 발생한다.
- 회차가 없는 달을 건너뛸 때 이전 `PENDING` 회차를 조기에 `MISSED` 처리하지 않는다.
- 특정 날짜 규칙의 누락 월 처리 뒤에도 원래 월간 간격을 유지한다.
