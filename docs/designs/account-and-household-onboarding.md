# 계정·가구 온보딩

## 모바일 최초 관리자 등록

`DS-003` 계정·가구 온보딩의 최초 설정 분기는 `D-099` 모바일 최초 관리자 등록과 `PR-AC-058` 최초 관리자 수용 기준을 따른다. `D-074` 최초 관리자 CLI의 과거 정책은 결정 등록부에 남아 있다.

1. 준비된 설치에서 운영자는 Android Chrome에 Tailscale HTTPS 주소를 열고 Google에 로그인한다.
2. 먼저 예약한 검증 계정이 후보가 된다. 화면에 계정 주소와 “이 계정이 Notify Me의 최초 관리자가 됩니다. 가구를 만들고 구성원을 초대할 수 있습니다.”를 표시한다. 설정 시작과 취소를 선택할 수 있다.
3. 확인은 현재 로그인과 후보의 일치를 검사한다. 한 트랜잭션이 첫 가구와 ADMIN을 함께 저장하고 기존 리마인더 화면을 연다. 완료 응답을 받지 못한 경우 같은 계정으로 로그인하면 저장된 결과를 확인할 수 있다.
4. 취소가 먼저 적용되면 후보가 즉시 해제된다. 창을 닫으면 최초 예약부터 10분 뒤에 만료된다. 새로고침 후 필요하면 같은 계정으로 다시 인증한다. 재인증은 유효기간을 연장하지 않는다.

후보 화면에서는 가구 데이터, 멤버십, 초대 기능에 접근할 수 없다. 기존 계정과 초대 대상은 원래 로그인·가입 경로를 사용한다. 복원 또는 가구 종료는 등록을 다시 열지 않는다. [설치 주기](../decisions/ADR-039-installation-setup-cycle.md), [후보 인가](../decisions/ADR-040-mobile-admin-candidate.md), [Pi 운영 가이드](../u1-local-run.md#tailscale로-모바일-웹-접속).
